This folder contains the approved/current visual references for the first Arrantza prototype.

Use the Master Design MD as the source of truth for mechanics and rules. These images are visual references. Do not invent gameplay systems from incidental details in the artwork.

## 10 — Double-Fish Logo Inspiration Reference

This is the user's original logo-form reference, retained intentionally for Codex.

Use it only as reference for:
- Two interlocking/opposed fish concept
- Basic flowing paired-fish silhouette relationship

The Arrantza-specific execution is the blue double-fish emblem already visible in the approved Title Screen and Stage Select references:
- upper fish: darker blue, but not the same darkest navy as the ARRANTZA wordmark
- lower fish: lighter blue, but not the same blue as the background sky
- emblem should feel integrated with the wordmark rather than pasted on

## Important interpretation rule

When an image and the Master Design appear to disagree:
1. Follow the Master Design for mechanics, progression, input, timings, state behavior, and scope.
2. Follow this manifest for what each reference image is intended to communicate.
3. Treat incidental/generated details not listed here as non-authoritative.
